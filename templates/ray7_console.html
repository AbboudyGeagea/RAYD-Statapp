What “held” means

These messages were received and are stored safely — nothing has been lost. RAY7 could not attach them to a study (no accession and no order number) or could not classify them (a status code with no mapping), so their contents have not reached the reports.

To release them: fix the cause — map the status code in the mapping studio, or point the accession mapping at the field this sender really uses — then press Replay held messages. Each one is checked again; those that now pass go into the reports, the rest stay here.
